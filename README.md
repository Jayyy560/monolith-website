# Monolith by Alex Panels — Complete Website Source

Latest published version, including the new overview pavilion image.

## Run locally
Extract this ZIP, then open index.html in your browser.
For a local web server, run: python -m http.server 8000
Then visit http://localhost:8000

## Files
- index.html: complete page markup and content
- style.css: responsive layout and visual styles
- script.js: parallax, scroll reveals, layer controls, colour selector and galleries
- assets/: all website images, fonts and logos
- downloads/: downloadable product documents

No npm install or build step is required. Upload these files together to any static web host, preserving folder paths.

The sample enquiry form downloads a request text file; it is not connected to an email service or backend. Generated architecture is conceptual imagery. Product specifications should be confirmed against the current approved product data before commercial use.

MONOLITH — by Alex Panels

Complete source for the two-section animated website.

Files
- index.html: page structure and editable copy
- style.css: styling, responsive layouts, and animation styles
- script.js: scroll-driven parallax and reveal animations
- assets/: sunset, clouds/birds, building cutout, and brochure system illustration

Run
Extract the ZIP and open index.html in a modern browser. No installation, API key, or build step is needed.
Alternatively, from the extracted directory run: python -m http.server 8000
Then open http://localhost:8000

Host
Upload index.html, style.css, script.js, and the assets folder together into your hosting directory (for example public_html). Keep the folder structure intact.

Editing
Change copy in index.html, styling in style.css, and scroll movement in script.js. Images are local assets. The site includes mobile layouts and respects reduced-motion preferences. The façade illustration is a conceptual assembly from the supplied brochure.

This standalone export contains the published website code and assets. Hosting-specific account configuration and Git history are intentionally excluded.
